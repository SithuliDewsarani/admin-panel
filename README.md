# Admin Panel

A simple and modern PHP-based Admin Dashboard developed using PHP, HTML, and CSS.

## Features

- Admin Login Page
- Forgot Password Page
- Reset Password Page
- Modern Admin Dashboard
- Sidebar Navigation
- Top Navigation Bar
- Manual Date and Time Display
- Profile Dropdown
- Dashboard Summary Cards
- Sample Bar Chart
- Sample Line Chart
- Recent Messages Section
- Quick Actions
- Responsive Design
- Logo Integration

## Technologies Used

- PHP
- HTML5
- CSS3
- XAMPP
- Apache Server
- Visual Studio Code
